# AaharSetu 🍎

### Citizen Food Business Transparency & Verification Platform

AaharSetu is a food safety and hygiene verification platform designed to help people make informed decisions about where they eat and shop.

The platform aims to improve transparency by helping citizens explore food businesses, verify licence details, and access food safety information.

## 🌐 Live Demo

**[Visit AaharSetu](https://aaharsetu.ai.studio/)**

## ✨ Key Features

- Explore food businesses.
- Access food licence and verification information.
- Discover food safety and hygiene information.
- User-friendly interface for citizens.
- AI-powered food information assistance.

## 🛠️ Technology

- React
- TypeScript
- Vite
- Node.js
- Google Gemini API
